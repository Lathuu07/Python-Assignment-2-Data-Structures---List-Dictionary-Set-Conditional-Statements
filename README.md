# Python Assignment 2: Data Structures – List, Dictionary, Set & Conditional Statements

## 📌 Description
This assignment focuses on understanding Python data structures and conditional statements through practical coding exercises. It covers creating, accessing, updating, and performing operations on Lists, Dictionaries, and Sets, along with decision-making using conditional statements.

## 📚 Topics Covered

### 1. Lists
- Creating a list
- Accessing list elements
- Adding and updating elements
- Understanding ordered and mutable collections

### 2. Dictionaries
- Creating dictionaries using key-value pairs
- Accessing dictionary values
- Adding new key-value pairs
- Updating existing values
- Using `keys()`, `values()`, and `items()` methods

### 3. Sets
- Creating sets
- Understanding unique elements
- Handling duplicate values
- Understanding set mutability and indexing limitations
- Performing set operations:
  - Union (`|`)
  - Intersection (`&`)
  - Difference (`-`)
  - Symmetric Difference (`^`)

### 4. Conditional Statements
- Understanding Python operators
- Arithmetic operators
- Comparison operators
- Logical operators
- Using `if`, `elif`, and `else` statements

### 5. Performance Category Program
Developed a Python program that accepts a score between 0 and 10 and identifies the performance category.

**Performance Criteria:**
- Above Average: Score greater than 7
- Average: Score between 4 and 7 (both inclusive)
- Below Average: Score less than 4

Also included motivational messages for each performance category.

- Python
- Google Colab

- Gained practical knowledge of Python data structures.
- Understood the differences between Lists, Dictionaries, and Sets.
- Practised adding, accessing, and updating data.
- Learned how to perform different set operations.
- Improved understanding of operators and conditional statements.
- Applied decision-making concepts through a real-world performance categorization program.
